# DragonMineZ: Sento Saiyan Race

A DragonMineZ addon that adds the Sento Saiyan race — primal Saiyans
from Universe 1 with white hair, red face markings, and a tail.

## Features

- Sento Saiyan race with custom Oozaru, Golden Oozaru, SSJ4 variants
- Legendary Forms (Ikari, SS Hybrid, SS Full Power)
- Three unique racial abilities:
  - **Flex** — channel ki into the limbs for a temporary power boost
  - **Sound Breaker** — short roar that stuns nearby targets
  - **Trigger Wave** — force nearby Sentos into Oozaru
- Optional compatibility with DMZ Overhaul (Revamp)
- Ki Sense through walls for Sento Mutants

## Requirements

- Minecraft 1.20.1
- Forge 47.4.20+
- DragonMineZ 2.1.3

## Installation

1. Drop the `.jar` in your `mods/` folder
2. Also install DragonMineZ and its dependencies
3. Launch the game

## Commands

- `/dmzsento reset config` — reinstall race files
- `/dmzsento reset flex` — clear Flex cooldown/state (admin)
