# Changelog

## [1.0.0] - 2026-09-30

Initial public release.

### Features
- Sento Saiyan race with Oozaru, Golden Oozaru, SSJ4, Legendary Forms
- Flex ability with overuse counter, numblock, sleep state
- Sound Breaker: short roar that stuns nearby targets
- Trigger Wave: forces nearby Sentos into Oozaru
- Ki Sense through walls for Sento Mutants
- Bed sleep recovery (1 numblock per night)
- Hot spring recovery (300s immersed)
- `/dmzsento reset flex` command
- Optional compatibility with DMZ Overhaul (Revamp)

## Known Issues

### Hair/base z-fighting
If you use DMZ Generations, hair may flicker at any ages. This is a 
Generations bug — remove the mod or wait for an upstream fix.
